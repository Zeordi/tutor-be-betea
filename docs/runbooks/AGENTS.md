# Support Escalation Contacts

## Roles

| Role | Scope |
|------|-------|
| SUPPORT_AGENT | Triage, routine issues, first response |
| FINANCE / SUPER_ADMIN | Escrow, billing, payout, payment provider issues |
| VERIFICATION_OFFICER | ID/document verification, risk flag appeals |

## Escalation Path

1. SUPPORT_AGENT receives ticket
2. Escrow/billing → FINANCE / SUPER_ADMIN
3. Trust/document issues → VERIFICATION_OFFICER
4. Safety/critical → immediate alert to on-call SUPER_ADMIN
