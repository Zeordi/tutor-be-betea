# Tutor Be Betea – Internal Beta Launch Checklist

## 1. Technical Readiness
- [ ] All critical flows tested (Auth, Hire, Check-in, Chat, Verification)
- [ ] Africa’s Talking OTP working with real numbers
- [ ] Error tracking enabled (Sentry or similar)
- [ ] Backend deployed to staging server
- [ ] Mobile app built with EAS (internal distribution)
- [ ] Database backups configured
- [ ] Redis running and persistent

## 2. Content & Support
- [ ] Support phone number ready
- [ ] Support Telegram / email ready
- [ ] Basic FAQ written (Amharic + English)
- [ ] Privacy Policy draft ready
- [ ] Terms of Service draft ready

## 3. People
- [ ] 5–10 trusted parents recruited in Addis Ababa
- [ ] 5–10 verified teachers recruited
- [ ] 1–2 internal admins trained on Verification Queue
- [ ] One person responsible for daily monitoring

## 4. Monitoring during Beta
- [ ] Check OTP delivery success rate daily
- [ ] Monitor failed check-ins
- [ ] Monitor chat for any anti-poaching false positives
- [ ] Collect feedback via Google Form or Telegram group
- [ ] Daily short standup (15 min)

## 5. Success Criteria for Beta
- [ ] At least 10 successful contracts created
- [ ] At least 20 verified sessions (check-ins)
- [ ] No critical security issues
- [ ] Average response time from support < 2 hours
- [ ] Positive feedback from majority of testers
